# Icon Files

## Quick Icon Generation

The easiest way to create the icon PNG files:

1. Open `generate_icons.html` in your browser
2. The icons will automatically download (icon128.png, icon48.png, icon16.png)
3. Move the downloaded files to this `icons` directory

## Manual Method

If the auto-download doesn't work:
1. Use an online SVG to PNG converter
2. Or use an image editor to create 16x16, 48x48, and 128x128 PNG files

## Temporary Workaround

The extension will work without custom icons - Chrome will show a default extension icon.
